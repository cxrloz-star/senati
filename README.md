# Login SENATI

Interfaz responsive de inicio de sesión para un portal académico.

## Archivos
- `index.html`: estructura del formulario.
- `styles.css`: estilos y diseño adaptable a móviles.
- `script.js`: validación básica del formulario y opción para mostrar/ocultar contraseña.

## Ejecutar
Abre `index.html` en tu navegador o utiliza la extensión Live Server de Visual Studio Code.

## Importante
Este repositorio contiene únicamente la interfaz de demostración. La validación del navegador **no autentica usuarios** ni protege páginas privadas. Para un inicio de sesión real, conecta el formulario a un backend y una base de datos; almacena contraseñas con hash seguro y valida las sesiones en el servidor.
